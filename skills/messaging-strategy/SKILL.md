# Messaging Strategy Agent

## When to use
Use this when teams say different things to the same buyer and the brand sounds like several companies at once. It fits the gap between a positioning statement and the words sales, marketing, and product actually use. Reach for it before a campaign or launch, when you need one governed set of messages everyone can pull from without freelancing.

## What it does
It produces a message house: a single core idea at the roof, a small set of supporting pillars, and proof points under each, giving every team a shared and defensible script for the same buyer.

## Method
This agent runs the message house architecture.

1. Anchor the roof.
   - Write the one core message, the single idea you want the buyer to remember, drawn straight from the positioning.
   - Keep it to one memorable line.
2. Choose the pillars.
   - Identify three to four supporting themes that hold the roof up.
   - Give each a distinct reason the buyer should believe or care, with no overlap between pillars.
3. Fill each pillar with proof.
   - List the concrete evidence, capabilities, outcomes, or features under each pillar.
   - Let no pillar stand without proof.
4. Pressure-test coverage.
   - Check that the pillars together answer the buyer's main questions and objections.
   - Make sure nothing important is homeless.
5. Tune for audience.
   - Note how the same core idea and pillars flex in emphasis for different buyer roles without changing the underlying claims.
6. Set usage rules.
   - Define the elevator version and the one-liner per pillar.
   - Name what teams must not say, so the house governs rather than merely suggests.
7. Map pillars to channels.
   - Note where each pillar works hardest across the funnel and channels.

## Inputs
- The positioning statement or core value promise
- The primary buyer and any secondary roles to address
- Key proof points: outcomes, capabilities, evidence, or features
- The main objections or competitor claims to answer
- Channels and campaigns the messaging must feed

## Output format
Claude returns a message house in prose:
- Roof: the single core message in one line.
- Pillars: each pillar named and explained in a sentence, with its proof points listed beneath as short evidence statements.
- Audience Tuning: how emphasis shifts by buyer role.
- Usage Rules: the elevator version, the one-liner per pillar, and the do-not-say list.
- Channel Map: where each pillar works hardest.

## Example
For Verdant Meal Kits, a fictional plant-based subscription, the roof reads: eat well without the weeknight scramble. Three pillars hold it up. Convenience: ten-minute recipes, pre-portioned ingredients, no planning, backed by prep-time data on every card. Health: dietitian-designed menus and full nutrition transparency. Sustainability: low-waste packaging and a lower-footprint menu than takeout. Each pillar carries concrete proof rather than adjectives.

For busy parents, convenience leads; for climate-conscious buyers, sustainability leads, while the core idea stays fixed. Usage rules give a one-line elevator pitch, a single line per pillar, and a do-not-say list that bars unproven health claims. The channel map sends convenience to paid social and sustainability to the site and packaging.

A sample pillar entry reads:
- Pillar: Convenience.
- Claim: dinner without the weeknight planning tax.
- Proof: ten-minute recipes, pre-portioned ingredients, prep-time data on every card.
- One-liner: real meals in the time it takes to order out.
- Leads for: busy parents and time-pressed households.
