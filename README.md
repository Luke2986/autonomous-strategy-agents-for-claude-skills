# 67 Autonomous Strategy Agents for Claude

A full strategy function, agentized. This pack contains 67 autonomous strategy agents for Claude, each delivered as a single SKILL.md file in its own folder. Together they run an entire strategy department end to end, from reading the market to briefing the board. Built for operators, consultants, analysts, founders, and strategy teams who want Claude to work like a top-tier strategy department instead of a one-off prompt.

Each agent teaches Claude one high-value strategy task with a repeatable, named method (PESTEL, Ansoff, Value Proposition Canvas, TAM/SAM/SOM, Porter value chain, RAPID, ADKAR, Pyramid Principle, SCQA, and more). Run one on its own, run a group for a phase, or chain the full set.

## What is inside

- 67 agents across 9 functions, one folder per agent, one SKILL.md each.
- Every SKILL.md has the trigger, the outcome, the step-by-step method, the inputs it needs, the output shape, and a worked example.

## Install

1. Unzip anywhere.
2. Add the folders to a Claude Project as Project Knowledge (Projects, Create Project, Project Knowledge, Add Content), or drop them into ~/.claude/skills/.
3. In a conversation, name the agent you want Claude to run, for example "Run the market-sensing agent." Chain several to move from market signal to board briefing in one sitting.
